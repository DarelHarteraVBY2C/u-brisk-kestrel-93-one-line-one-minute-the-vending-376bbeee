Entry for the [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) bounty on make.fun: one line, max 200 characters — a pickup line a vending machine would use on a passing human.

## The entry

> Psst — press B7: I'm the only machine on this floor that gives exact change, warm snacks, and absolutely zero mixed signals.

## How to run

Requires Node 22. The program writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating the gate first: 1–200 characters, one line, not only whitespace.

```sh
node main.ts
```

No network, no dependencies, fully deterministic.
